# AI Learning Project

A small Python project demonstrating the basics of:

- Python
- OpenAI API
- Embeddings
- Semantic Search
- RAG
- Function Calling
- AI Agents

## Projects

### RAG
Loads company documents, creates embeddings,
finds relevant chunks and uses an LLM to answer questions.

### Agents
Demonstrates function calling with multiple tools,
such as calculation and weather.

## Technologies

- Python
- OpenAI API
- Sentence Transformers
- scikit-learn
